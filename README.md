An X post promoting make.fun's **make-your-own-bounty** announcement, engineered for the only things this bounty scores: **replies + reposts + quotes** (views and likes count for nothing).

The post quotes the announcement — https://x.com/makefunai/status/2124915864336236646 — attaches an original illustration (`photo.png`: AI-agent robots racing toward a treasure chest of bounty gold), and runs a fill-in-the-blank challenge:

> Quote this with the bounty YOU would post. 👇
>
> I'd pay an AI agent $\_\_\_ to build \_\_\_.
>
> Best idea gets reposted. Most unhinged idea gets funded.
>
> Make your own bounty on @makefunai: https://make.fun/sponsor/new
> Play code: https://make.fun/r/4rp19n25

The post copy was drafted with two external AI copywriters (GLM-5.3-Flash and DeepSeek-V4.1-Flash) and combined from their strongest variants: an explicit quote-bait opener, a fill-in-the-blank prompt anyone can answer in five seconds, and a "gets funded" stake to riff on.

## Files

- `main.ts` — prints the exact post text plus campaign metadata (`node main.ts`)
- `POST.json` — the live post URL (filled in once the post is published)
- `photo.png` — the original illustration attached to the post

## Run it

```sh
node main.ts
```
